MentoHUST BetterUI 使用说明

一、第一次使用
1. 把下载的 ZIP 解压到一个固定文件夹，不要直接在压缩包里打开程序。
2. 双击 MentoHUST.BetterUI.exe。只需要打开这一个程序。
3. 点击“设置”，填写校园网账号和密码，点击“添加／更新”，然后点击“确定”。
   如果以前用过旧版，也可以点击“导入配置”，选择旧版的 Config.ini。
4. 回到首页，选择你的账号和联网网卡。插网线使用校园网时，通常选择“以太网”对应的网卡。
5. 点击“开始认证”，看到“已认证”后就可以使用校园网了。

二、开机自动连接
先手动认证成功一次。然后打开“设置”的“参数设置”，勾选“开机后自动运行”和“运行后自动认证”，点击“确定”。
下次登录 Windows 时，程序会打开，并等待网卡准备好后自动认证。请把程序放在固定位置；如果移动了文件夹，请重新保存一次开机运行设置。
只想打开程序后自动连接，也可以只勾选“运行后自动认证”。

三、收起窗口和热点
勾选“认证成功后最小化到托盘”后，认证成功会稍等半秒再收起。右下角任务栏的小图标可以重新打开窗口。
需要认证后开启热点，可以勾选对应选项。旁边的问号有说明；热点名称和密码在 Windows 的“移动热点”设置里修改。
如果提示权限不足，请右键程序，选择“以管理员身份运行”。

四、连接不上怎么办
先确认账号密码正确、网线已连接、网卡选对，并关闭其他正在认证的客户端。
如果开始认证按钮不能点击，检查账号是否保存、网卡是否选好，并查看窗口下方的提示。
如果提示抓包驱动不可用，需要安装 Npcap，并在安装时勾选 WinPcap 兼容模式；原来已经能认证的电脑通常不用重装。
如果提示缺少运行库，安装微软 Visual C++ 2015–2022 可再发行组件（x86）。
仍然连接不上时，请把窗口下方的错误提示发给维护者。

五、更新程序
关闭旧程序，把新版本解压到原来的文件夹，再打开即可。账号和设置保存在电脑里，更新程序不会要求重新填写。
下载时选择名字为 MentoHUST-BetterUI-版本号.zip 的文件；GitHub 的 Source code 是开发用源码，日常使用不需要下载。
认证后台已包含在主程序中，打开时会自动准备，不需要另外下载或打开第二个 EXE。
